ทำให้เสร็จก่อนเรียนครั้งแรก

ติดตั้งก่อนเรียน Codex

ทำทีละข้อบนเครื่อง Windows ของบริษัท แต่ละข้อมีวิธีเช็กว่าลงสำเร็จแล้ว

กฎ 3 ข้อ จำไว้ตลอดคอร์ส

  • ใน Codex เลือก Ask for approval ไว้ตลอด Codex จะถามก่อนทำอะไรเสี่ยง ห้ามเลือก Full access เพราะมันจะแก้หรือลบไฟล์นอกโฟลเดอร์งานได้
  • ห้ามพิมพ์หรือแนบรหัสผ่าน ข้อมูลลูกค้า หรือข้อมูลลับของบริษัท
  • เปิดให้ Codex เห็นแค่โฟลเดอร์ฝึก ห้ามเปิดทั้ง Desktop หรือไดรฟ์แชร์

รายการติดตั้ง

ลงโปรแกรมแค่คลิก ไม่ต้องพิมพ์คำสั่ง ถ้าเครื่องขอรหัส admin ให้แจ้ง IT ลงเสร็จแล้วเช็กได้ใน PowerShell: กดปุ่ม Start พิมพ์ PowerShell แล้วกด Enter จากนั้นพิมพ์คำสั่งที่ให้ไว้ในแต่ละข้อ แล้วกด Enter (ลงโปรแกรมเสร็จแล้วต้องเปิด PowerShell ใหม่)

  1. ลงแอป ChatGPT

    ทุกคนต้องทำ

    Codex อยู่ในแอปนี้ เป็นตัวหลักที่ใช้ทั้งคอร์ส

    เปิด Microsoft Store ค้นหา ChatGPT เลือกตัวที่เขียนว่า OpenAI แล้วกดติดตั้ง

    ผลที่ควรเห็น

    ในเมนู Start มีแอป ChatGPT และเปิดได้

    ถ้าไม่ได้: ถ้าเปิด Microsoft Store ไม่ได้ ให้แจ้ง IT ช่วยลงให้ ถ้าเจอแอปชื่อ ChatGPT Classic อันนั้นเป็นรุ่นเก่า ไม่ใช่ตัวที่ใช้เรียน

  2. เข้าสู่ระบบด้วยบัญชีบริษัท

    ทุกคนต้องทำ

    คอร์สนี้ใช้ ChatGPT ของบริษัท งานที่ทำในบัญชีบริษัท โดยปกติจะไม่ถูกเอาไปฝึก AI

    เปิดแอป กด Sign in แล้วใช้อีเมลบริษัท ถ้ามีให้เลือก workspace ให้เลือกของบริษัท

    ผลที่ควรเห็น

    เปลี่ยนเมนูด้านบนของแอปเป็น Codex ได้ และบัญชีที่ใช้อยู่เป็นของบริษัท

    ถ้าไม่ได้: ถ้าเข้าไปแล้วเป็นบัญชีส่วนตัว ให้ออกจากระบบ แล้วเข้าใหม่ด้วยอีเมลบริษัท

  3. ลง Git

    ทุกคนต้องทำ

    Git ช่วยเซฟงานไว้เป็นจุด ๆ ถ้า Codex แก้พลาดก็ย้อนกลับได้ เราไม่ต้องใช้เอง Codex จะใช้ให้

    1. เปิดเว็บ git-scm.com/download/win แล้วโหลดตัวติดตั้ง
    2. เปิดไฟล์ที่โหลดมา กด Next ไปเรื่อย ๆ ไม่ต้องเปลี่ยนอะไร แล้วกด Install

    ผลที่ควรเห็น

    ในเมนู Start มีโปรแกรมชื่อ Git Bash

    หรือเปิด PowerShell พิมพ์ git --version ต้องขึ้น git version ตามด้วยเลขรุ่น

  4. ลง Python

    ทุกคนต้องทำ

    Codex จะเขียนโปรแกรมเล็ก ๆ ด้วย Python ไว้รวมไฟล์ Excel หรือ CSV และทำรายงานให้

    1. เปิดเว็บ python.org/downloads/windows เลือกรุ่นล่าสุด แล้วโหลด Windows installer (64-bit)
    2. เปิดไฟล์ที่โหลดมา ติ๊กช่อง Add python.exe to PATH ด้านล่างก่อน แล้วกด Install Now

    ผลที่ควรเห็น

    ในเมนู Start มีโปรแกรมชื่อ Python 3 ตามด้วยเลขรุ่น

    หรือเปิด PowerShell พิมพ์ python --version ต้องขึ้น Python 3 ตามด้วยเลขรุ่น ถ้าขึ้นว่า Python was not found หรือ Microsoft Store เด้งขึ้นมา แปลว่าไม่ได้ติ๊ก Add python.exe to PATH

    ถ้าไม่ได้: ถ้าลืมติ๊ก Add python.exe to PATH ให้ถอน Python ออก แล้วลงใหม่ คราวนี้ติ๊กช่องนั้นด้วย

  5. ลง Node.js (รุ่น LTS)

    ทุกคนต้องทำ

    ใช้เปิดระบบตัวอย่างที่ใช้ฝึก และใช้รันเทสอัตโนมัติ

    1. เปิดเว็บ nodejs.org แล้วโหลดรุ่น LTS แบบ Windows Installer (.msi)
    2. เปิดไฟล์ที่โหลดมา กด Next ไปเรื่อย ๆ ไม่ต้องเปลี่ยนอะไร แล้วกด Install

    ผลที่ควรเห็น

    ในเมนู Start มีโฟลเดอร์หรือโปรแกรมชื่อ Node.js

    หรือเปิด PowerShell พิมพ์ node -v ต้องขึ้นเลขรุ่นที่ขึ้นต้นด้วย v

  6. ลง VS Code กับส่วนเสริม Codex

    ทุกคนต้องทำ

    เอาไว้เปิดอ่านและแก้ไฟล์ที่ Codex ทำให้ เช่น ไฟล์เทส หรือโปรแกรม Python

    1. เปิดเว็บ code.visualstudio.com กด Download for Windows แล้วลงตามที่ตั้งไว้ ไม่ต้องเปลี่ยนอะไร
    2. เปิด VS Code กด Ctrl+Shift+X ค้นหา Codex เลือกตัวที่เขียนว่า OpenAI กด Install แล้วเข้าสู่ระบบด้วยบัญชีบริษัท

    ผลที่ควรเห็น

    แถบด้านข้างของ VS Code มีไอคอน Codex และกดคุยได้ (เช็กว่าลง VS Code แล้ว: เปิด PowerShell พิมพ์ code --version บรรทัดแรกต้องเป็นเลขรุ่น)

  7. สร้างโฟลเดอร์ไว้ฝึก

    ทุกคนต้องทำ

    Codex ทำงานได้แค่ในโฟลเดอร์ที่เราเปิดให้ ทั้งคอร์สใช้โฟลเดอร์นี้โฟลเดอร์เดียว

    1. เปิด File Explorer (กดปุ่ม Windows+E)
    2. คลิกช่องที่อยู่ด้านบน พิมพ์ %USERPROFILE% แล้วกด Enter
    3. คลิกขวาที่ว่าง เลือก New แล้วเลือก Folder ตั้งชื่อว่า codex-practice

    ผลที่ควรเห็น

    มีโฟลเดอร์ C:\Users\ชื่อของคุณ\codex-practice

  8. ลองใช้ Codex ครั้งแรก

    ทุกคนต้องทำ
    1. เปิดแอป ChatGPT แล้วเปลี่ยนเมนูด้านบนเป็น Codex
    2. เปิดโฟลเดอร์ codex-practice ที่เพิ่งสร้าง
    3. ใต้ช่องพิมพ์ เลือก Ask for approval
    4. คัดลอกข้อความด้านล่างไปวางทีละอัน แล้วกดส่ง
    สร้างไฟล์ hello.txt ในโฟลเดอร์นี้ เขียนข้างในว่า สวัสดี Codex
    ดูหน่อยว่าเครื่องนี้มี git, node, python หรือยัง บอกเลขรุ่นด้วย ไม่ต้องลงอะไรเพิ่ม

    ถ้า Codex ขออนุญาต ให้อ่านก่อนว่ามันจะทำอะไร แล้วค่อยกดอนุญาต

    ผลที่ควรเห็น

    มีไฟล์ hello.txt ในโฟลเดอร์ และ Codex บอกเลขรุ่นของ git, node และ python ได้ครบ

    ถ้าไม่ได้: ถ้า Codex บอกว่าหาโปรแกรมที่ลงไปแล้วไม่เจอ ให้ปิดแอป ChatGPT แล้วเปิดใหม่ ยังไม่เจออีกให้รีสตาร์ตเครื่อง

  9. ขอสิทธิ์เข้าระบบ TEST ของบริษัท

    สาย QAไม่บังคับ

    ตอนเรียนใช้ระบบตัวอย่างในไฟล์ฝึก สิทธิ์นี้เอาไว้ใช้ตอนเรียนจบแล้วไปทำงานจริง ขอไว้ก่อนได้ ห้ามใช้บัญชีหรือระบบจริง (production)

    ขอจากหัวหน้าหรือ IT 2 อย่าง (ไม่ต้องขอสิทธิ์เข้าฐานข้อมูล)

    1. บัญชี git server ของบริษัท
    2. บัญชีผู้ใช้ทดสอบในระบบ TEST

    ผลที่ควรเห็น

    เข้าระบบ TEST ด้วยบัญชีทดสอบได้ และเปิดหน้า git server ของบริษัทได้

ไม่ต้องลงเอง

  • WSL กับ Docker: Codex บน Windows ไม่ต้องใช้
  • Playwright: ในห้องเรียนจะให้ Codex ลงให้
  • Codex CLI: ไม่ต้องลง ถ้าต้องใช้ผู้สอนจะบอก

ติดตรงไหน ดูตรงนี้

เครื่องขอรหัส admin
ไม่ต้องหารหัสเอง แจ้ง IT ว่าต้องลงโปรแกรมอะไรบ้าง ส่งหน้านี้ไปให้ดูได้เลย
เปิด Microsoft Store หรือเว็บดาวน์โหลดไม่ได้
แจ้ง IT ให้ลงให้ ส่งลิงก์หน้านี้ไปด้วย
ลงแล้ว แต่ PowerShell ขึ้นว่า is not recognized หรือ Codex บอกว่าหา git, node, python ไม่เจอ
ปิด PowerShell หรือแอป ChatGPT แล้วเปิดใหม่ ยังไม่ได้ให้รีสตาร์ตเครื่อง ยังไม่ได้อีกให้ลงโปรแกรมนั้นใหม่
Windows ถามว่าจะเปิดไฟล์ที่โหลดมาไหม
เช็กว่าโหลดมาจากเว็บที่ลิงก์ไว้ในหน้านี้ แล้วกดเปิดได้เลย

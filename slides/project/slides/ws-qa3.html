ลองทำ QA-3

เขียนเทสหน้าเว็บอัตโนมัติชุดแรก

  1. ใน File Explorer สร้างโฟลเดอร์ qa-tests ใน codex-practice แล้วคัดลอก testcases.csv กับ requirements\requirements.md จาก practice-kit\qa มาวาง
  2. เปิดโฟลเดอร์ qa-tests ใน Codex ส่งข้อความทางขวา ถ้า Codex ขอใช้อินเทอร์เน็ต ให้กดอนุญาต
  3. ให้ Codex สร้าง AGENTS.md แบบโฟลเดอร์เทส (คู่มือหัวข้อ 5) แล้วสั่งเขียนเทสจาก testcases.csv (คู่มือ QA-3)
  4. สั่ง: รันเทสทั้งหมด 3 รอบ แล้วแยกว่าข้อไหนไม่ผ่านเพราะระบบผิด

พิมพ์ให้ Codex
ตั้งโปรเจกต์ Playwright ในโฟลเดอร์นี้ ด้วย npm init playwright@latest -- --quiet --browser=chromium --lang=ts แล้วเปิดใช้ git และ commit ทุกไฟล์
ตั้งให้เทสไปที่ http://127.0.0.1:3100 ใช้ chromium อย่างเดียว รันทีละเทส (workers 1) แล้วลบไฟล์ตัวอย่าง example.spec.ts
บัญชีทดสอบให้อ่านจาก TEST_USER กับ TEST_PASSWORD ถ้าไม่มี ใช้ requester1 / demo1234 (บัญชีสมมติ)

ทำได้แล้ว ถ้า เทสที่ผ่าน ผ่านครบทั้ง 3 รอบ และเทสที่ไม่ผ่าน บอกได้ว่าไม่ตรงข้อกำหนดข้อไหน โดยไม่ได้แก้เทสให้ผ่าน

ต้องเปิด start.bat ไว้ก่อนรันเทส ถ้า Codex รัน npm ไม่ได้เพราะ running scripts is disabled ให้บอกให้ใช้ npm.cmd กับ npx.cmd แทน รัน 3 รอบ เทสที่สร้างคำขอเดิมซ้ำจะได้ 409 ตาม REQ-09 ซึ่งถูกต้อง ให้เทสเรียก /api/reset ก่อนแต่ละเทส หรือเปลี่ยนวันที่ เดินดูว่าไม่มีใครแก้ค่าที่คาดไว้ให้ตรงกับระบบ ระบบจริงของบริษัทต้องเก็บรหัสในตัวแปรเท่านั้น ห้ามใส่ในไฟล์

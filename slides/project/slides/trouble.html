Codex บอกว่าเสร็จ แต่ไฟล์ไม่เปลี่ยนสั่ง Codex: ใช้ git เช็กว่าไฟล์ไหนเปลี่ยน แสดงผลจริงให้ดู
Codex แก้ไฟล์เกินที่สั่งสั่งย้อนกลับจุดล่าสุด แล้วสั่งใหม่ บอกว่า แก้แค่ไฟล์นี้
สั่งแก้แล้วก็ยังผิดอยู่หยุดก่อน เริ่มแชตใหม่ด้วย /new แล้ววาง error ทั้งหมดให้ดู
เปิดใน Excel แล้วภาษาไทยเพี้ยนบอก Codex: บันทึกใหม่ให้ Excel เปิดภาษาไทยได้
ขึ้นว่า running scripts is disabledบอก Codex: ใช้ npm.cmd กับ npx.cmd แทน
Codex บอกว่าไม่เจอ git, node หรือ pythonปิดแอปแล้วเปิดใหม่ ยังไม่ได้ให้รีสตาร์ตเครื่อง
ตารางเต็มอยู่ท้ายคู่มือ ติดเรื่องรหัส admin หรือเน็ตบริษัทบล็อก ให้จดไว้แล้วแจ้ง IT ไม่ต้องแก้เองในห้อง

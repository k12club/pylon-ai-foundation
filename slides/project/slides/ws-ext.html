ติดตั้ง skill ของทีม และต่อ MCP ตัวแรก

  1. ใน File Explorer เปิด practice-kit\common\team-skills คลิกขวาโฟลเดอร์ data-check แล้วเลือก Copy
  2. พิมพ์ %USERPROFILE% ในช่องที่อยู่ด้านบน กด Enter เข้าโฟลเดอร์ .agents แล้ว skills (ถ้าไม่มีให้สร้าง) แล้ว Paste
  3. ปิดแอป ChatGPT แล้วเปิดใหม่ สั่ง $data-check กับไฟล์ใน practice-kit\biz\reports
  4. สาย QA: ไปที่ Settings > MCP servers > Add server ใส่ค่าทางขวา กด Save แล้ว Restart จากนั้นพิมพ์ /mcp

ค่าที่ใส่ใน Add server (สาย QA)
ชื่อ: playwright
ชนิด: STDIO
คำสั่ง: npx @playwright/mcp@latest

พิมพ์ให้ Codex
ใช้ MCP playwright เปิด http://127.0.0.1:3100 แล้วบอกว่าหน้าเข้าสู่ระบบมีปุ่มอะไรบ้าง อย่ากดอะไร

ทำได้แล้ว ถ้า $data-check ตอบเป็นตารางปัญหาของข้อมูล และสาย QA เห็น playwright ใน /mcp

สายหน่วยงานเปิดดูหน้า Settings MCP servers กับ Plugins ได้ แต่ยังไม่ต้องติดตั้ง ถ้า Windows ไม่ยอมให้ตั้งชื่อโฟลเดอร์ที่ขึ้นต้นด้วยจุด ให้พิมพ์ .agents. (มีจุดท้าย) ถ้าแอปแยกช่อง arguments ให้ใส่ npx ในช่องคำสั่ง และ @playwright/mcp@latest ในช่อง arguments ถ้า MCP ไม่ขึ้นบน Windows ลองเปลี่ยนเป็น npx.cmd ก่อนลองต้องเปิด start.bat ของระบบตัวอย่างไว้

ลองทำ BIZ-2

รวมรายงานรับวัสดุจาก 3 ไซต์

  1. เปิดโฟลเดอร์ practice-kit\biz ใน Codex แล้วสั่ง commit จุดแรกไว้
  2. ขั้นแรก ให้ Codex ดูก่อนว่าข้อมูลผิดตรงไหน (ข้อความทางขวา)
  3. ขั้นต่อไป ให้ทำโปรแกรมรวมไฟล์ กับไฟล์ดับเบิลคลิก run.bat (ข้อความอยู่ในคู่มือ BIZ-2)
  4. เลือก 1 ไซต์ 1 วัสดุ คิดเองใน Excel แล้วเทียบกับที่โปรแกรมสรุป

พิมพ์ให้ Codex
ช่วยดูทุกไฟล์ใน reports/ กับ price-list.csv ยังไม่ต้องทำโปรแกรม และห้ามแก้ไฟล์
บอกเป็นตารางว่าข้อมูลมีปัญหาอะไรบ้าง: ปัญหา | ไฟล์ | กี่แถว | ตัวอย่าง
ดูอย่างน้อย: แถวว่าง แถวซ้ำ วันที่เขียนหลายแบบ (พ.ศ./ค.ศ.) ชื่อไซต์สะกดไม่เหมือนกัน ตัวเลขที่ใส่เป็นข้อความหรือมีคอมมา หน่วยไม่ตรงกับ price-list.csv

ทำได้แล้ว ถ้า เจอปัญหาครบทุกแบบ และยอดรวมตรงกับที่ผู้สอนเฉลย

เฉลย: ปัญหา 7 แบบ ยอดรวม 2,625,270.30 บาท ถ้าได้ 2,710,218.30 คือไม่ได้ตัดแถวซ้ำ, 2,479,065.30 คือนับตันเป็นถุง, 2,391,066.30 คือทิ้งแถวที่มีคอมมา ถ้า pip install ไม่ผ่าน แจก site-c-fallback.csv (ไฟล์นี้จะเจอปัญหาแค่ 6 แบบ)

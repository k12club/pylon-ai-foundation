ไม่ต้องจำคำสั่ง บอก Codex ได้เลย

อยากทำพิมพ์บอก Codex
เริ่มใช้กับโฟลเดอร์ใหม่เปิดใช้ git ในโฟลเดอร์นี้ แล้ว commit จุดแรกให้หน่อย
เซฟจุดcommit งานตอนนี้ไว้ ตั้งชื่อว่า ก่อนแก้รายงาน
ดูว่าแก้อะไรไปบ้างใช้ git เช็กให้ดูหน่อย ว่าแก้ไฟล์ไหนไปบ้าง แก้อะไร
ย้อนกลับย้อนทุกไฟล์กลับไปจุดที่ commit ล่าสุด
ดูจุดที่เคยเซฟแสดงประวัติ commit ทั้งหมด

เซฟก่อนสั่งงานทุกครั้ง พังเมื่อไหร่ก็ย้อนกลับได้

git คือโปรแกรมที่จำทุกจุดที่เราเซฟไว้ commit คือคำของ git แปลว่าเซฟจุด คนที่อยากพิมพ์เอง: git status, git diff, git add -A แล้ว git commit -m, git restore . ไฟล์ใหม่ที่ Codex สร้างต้องลบด้วย git clean ซึ่งลบแล้วหายเลย ให้ Codex บอกรายชื่อไฟล์ที่จะลบก่อนทุกครั้ง

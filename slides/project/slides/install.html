โปรแกรมที่ทุกคนต้องลง

โปรแกรมเอาไว้ทำอะไรลงยังไง
แอป ChatGPT (มี Codex ในตัว)ตัวหลักที่ใช้ทั้งคอร์สMicrosoft Store ค้นหา ChatGPT แล้วเข้าสู่ระบบด้วยอีเมลบริษัท
Gitให้ Codex เซฟจุด และย้อนกลับได้git-scm.com/download/win แล้วกด Next จนจบ
Pythonรันโปรแกรมจัดการ Excel ที่ Codex เขียนให้python.org ติ๊ก Add python.exe to PATH ก่อนกด Install
Node.js (รุ่น LTS)เปิดระบบตัวอย่าง และรันเทสnodejs.org แล้วกด Next จนจบ
VS Codeเปิดอ่านและแก้ไฟล์ที่ Codex ทำให้code.visualstudio.com

ลงให้ครบทุกตัว ไม่ต้องลง WSL หรือ Docker ถ้าเครื่องขอรหัส admin ให้แจ้ง IT

ส่งภาพหน้าจอของสไลด์หน้านี้กับหน้าถัดไปให้ผู้เรียนก่อนเรียน 1 สัปดาห์ (อย่าแชร์ทั้งชุดสไลด์ เพราะโน้ตผู้สอนมีเฉลย) ถ้า Microsoft Store ถูกบล็อก ให้ IT ลงให้ ถ้าเจอแอปชื่อ ChatGPT Classic อันนั้นเป็นรุ่นเก่า ถ้าเข้าแอปแล้วเป็นบัญชีส่วนตัว ให้ออกจากระบบแล้วเข้าใหม่ด้วยอีเมลบริษัท

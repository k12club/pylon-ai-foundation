# ชุดฝึก Codex

ข้อมูลทั้งหมดในชุดนี้เป็นข้อมูลสมมติ ชื่อบริษัท โครงการ และผู้ขายไม่มีอยู่จริง

วิธีแตกไฟล์ (ไม่ต้องพิมพ์คำสั่ง):

1. คลิกขวาที่ `practice-kit.zip` แล้วเลือก Extract All
2. กด Browse แล้วเลือกโฟลเดอร์ `codex-practice` (ถ้ายังไม่มี ให้สร้างโฟลเดอร์นี้ใน `C:\Users\<ชื่อ>` ก่อน)
3. กด Extract จะได้โฟลเดอร์ `codex-practice\practice-kit`

ตอนฝึก ให้เปิดใน Codex เฉพาะโฟลเดอร์ย่อยของเรื่องที่กำลังฝึก

วิธีเปิด: ในแอปกด Add new project (Ctrl+O) แล้วเลือกโฟลเดอร์นั้น จะได้ project ใหม่ในแถบซ้าย ส่วน project เดิมยังอยู่ กดสลับไปมาได้

| โฟลเดอร์ | ใช้ฝึก |
|---|---|
| `common\session1` | บันทึกประชุมและอีเมลจากผู้ขาย สำหรับฝึกสรุป ทำตาราง และร่างอีเมล |
| `common\session2` | ไฟล์ยอดขาย 3 สาขา สำหรับฝึกให้ Codex รวมเป็นสรุป 1 ไฟล์ |
| `qa\requirements` | ข้อกำหนดของระบบเบิกวัสดุ (QA-1) |
| `qa\app` | ระบบเบิกวัสดุตัวอย่าง (QA-2 ถึง QA-5) วิธีเปิดอยู่ใน `qa\README.md` |
| `biz\reports` | รายงานรับวัสดุประจำวันจาก 3 ไซต์งาน (BIZ-2 และ BIZ-4) |
| `biz\price-list.csv`, `biz\letter-template.txt` | ราคาวัสดุ และแบบหนังสือสรุปการรับวัสดุ (BIZ-2 ถึง BIZ-4) |
| `common\team-skills` | ตัวอย่าง skill ของทีม สำหรับฝึกติดตั้ง skill |

ข้อควรระวัง:

- ถ้าเปิดไฟล์ CSV ดูใน Excel อย่ากดบันทึกทับไฟล์ต้นฉบับ Excel จะเปลี่ยนรูปแบบวันที่และตัวเลข
- ก่อนเริ่มแต่ละเรื่อง ให้ Codex เซฟจุดไว้ก่อน พิมพ์ว่า `เปิดใช้ git ในโฟลเดอร์นี้ แล้ว commit ทุกไฟล์` (คู่มือหัวข้อ 4) พังเมื่อไหร่จะได้ย้อนกลับได้

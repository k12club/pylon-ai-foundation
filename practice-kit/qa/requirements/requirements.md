## ข้อกำหนด

- **REQ-01** ผู้ใช้เข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่าน ถ้าถูกต้องระบบออก token ถ้าไม่ถูกต้องแสดง "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง" (API ตอบ 401)
- **REQ-02** ทุก API ยกเว้นการเข้าสู่ระบบ ต้องส่ง header `Authorization: Bearer <token>` ถ้าไม่มีหรือไม่ถูกต้อง ตอบ 401
- **REQ-03** มี 2 บทบาท: ผู้ขอเบิก (requester) สร้างและดูคำขอได้ ผู้อนุมัติ (approver) ดูและตัดสินคำขอได้ แต่สร้างคำขอไม่ได้ (ตอบ 403)
- **REQ-04** การสร้างคำขอต้องระบุ วัสดุ จำนวน ไซต์งาน วันที่ต้องการใช้ (รูปแบบ YYYY-MM-DD) และหมายเหตุ (ไม่บังคับ) สร้างสำเร็จได้สถานะ "รออนุมัติ" และเลขที่เอกสาร MR-xxxx เรียงต่อจากเลขล่าสุด (ตอบ 201)
- **REQ-05** จำนวนต้องเป็นจำนวนเต็มตั้งแต่ 1 ถึง 500 ถ้าไม่ใช่ให้ปฏิเสธพร้อมข้อความ (ตอบ 400)
- **REQ-06** หมายเหตุยาวได้ไม่เกิน 200 ตัวอักษร นับทุกอักขระทั้งไทยและอังกฤษ ถ้าเกินให้ปฏิเสธ (ตอบ 400)
- **REQ-07** ถ้าข้อมูลที่ส่งมาไม่ครบหรือไม่ถูกต้อง เช่น รหัสวัสดุหรือรหัสไซต์งานที่ไม่มีในระบบ วันที่ผิดรูปแบบ หรือ JSON ผิดรูปแบบ API ต้องตอบ 400 พร้อมช่อง `error` บอกสาเหตุ และต้องไม่ตอบ 5xx
- **REQ-08** มูลค่าสินค้า = จำนวน x ราคาต่อหน่วย ภาษีมูลค่าเพิ่ม = 7% ของมูลค่าสินค้า ปัดเป็นทศนิยม 2 ตำแหน่ง โดยทศนิยมตำแหน่งที่ 3 ตั้งแต่ 5 ขึ้นไปให้ปัดขึ้น ยอดสุทธิ = มูลค่าสินค้า + ภาษีมูลค่าเพิ่ม API ส่งค่าเงินเป็นตัวเลขหน่วยบาท ทศนิยมไม่เกิน 2 ตำแหน่ง ตัวอย่าง: ทรายหยาบ 2 ลบ.ม. = 840.00, ภาษี 58.80, ยอดสุทธิ 898.80
- **REQ-09** ผู้ขอเบิกสร้างคำขอที่มี วัสดุ ไซต์งาน และวันที่ต้องการใช้ ตรงกับคำขอของตนเองที่ยังมีสถานะ "รออนุมัติ" ไม่ได้ (ตอบ 409 พร้อมข้อความ "มีคำขอนี้อยู่แล้ว")
- **REQ-10** หน้ารายการแสดงคำขอทั้งหมด เรียงเลขที่เอกสารจากใหม่ไปเก่า แต่ละแถวแสดง เลขที่ วันที่ต้องการใช้ (วว/ดด/ปปปป เป็น พ.ศ.) วัสดุ จำนวนและหน่วย ไซต์งาน ผู้ขอ ยอดสุทธิ (มีคอมมาคั่นหลักพัน ทศนิยม 2 ตำแหน่ง) และสถานะ
- **REQ-11** กรองรายการตามสถานะ และ/หรือ ไซต์งานได้ ถ้าใช้ทั้งสองอย่างต้องตรงทั้งสองเงื่อนไข
- **REQ-12** กรองตามวันที่ต้องการใช้ ด้วย "ตั้งแต่วันที่" และ "ถึงวันที่" โดยรวมทั้งวันเริ่มต้นและวันสิ้นสุด ระบุเพียงด้านเดียวก็ได้
- **REQ-13** ค้นหาด้วยข้อความบางส่วนของ ชื่อวัสดุ รหัสวัสดุ หรือหมายเหตุ ตรงส่วนใดของข้อความก็ได้ รองรับภาษาไทยและอังกฤษ ไม่แยกตัวพิมพ์เล็กใหญ่
- **REQ-14** ท้ายตารางแสดงยอดรวมของยอดสุทธิของรายการที่แสดงอยู่ (หลังกรองและค้นหา) โดยไม่นับรายการสถานะ "ไม่อนุมัติ"
- **REQ-15** เฉพาะผู้อนุมัติเท่านั้นที่อนุมัติหรือไม่อนุมัติได้ ผู้ขอเบิกเรียกใช้ต้องได้ 403 การไม่อนุมัติต้องระบุเหตุผล 1 ถึง 200 ตัวอักษร (ถ้าไม่ระบุ ตอบ 400)
- **REQ-16** สถานะเปลี่ยนได้เฉพาะจาก "รออนุมัติ" เป็น "อนุมัติแล้ว" หรือ "ไม่อนุมัติ" คำขอที่ตัดสินแล้วเปลี่ยนสถานะอีกไม่ได้ (ตอบ 409)
- **REQ-17** ระบบเก็บข้อมูลในหน่วยความจำ เมื่อเปิดระบบใหม่หรือเรียก `POST /api/reset` (ต้องเข้าสู่ระบบ) ข้อมูลกลับเป็นชุดตั้งต้นและเลขที่เอกสารเริ่มนับใหม่ หลัง `POST /api/reset` token ที่ออกไปแล้วยังใช้ได้ แต่หลังเปิดระบบใหม่ต้องเข้าสู่ระบบใหม่

# ระบบเบิกวัสดุตัวอย่าง

ใช้ฝึก QA-2 ถึง QA-5 ต้องติดตั้ง Node.js ก่อน ไม่ต้องติดตั้งอย่างอื่นเพิ่ม

## เปิดระบบ

1. เปิด File Explorer ไปที่ `codex-practice\practice-kit\qa\app`
2. ดับเบิลคลิกไฟล์ `start.bat` จะมีหน้าต่างสีดำเปิดขึ้นมา เปิดทิ้งไว้ตลอดที่ฝึก
3. เปิดเบราว์เซอร์ไปที่ http://127.0.0.1:3100
4. เลิกฝึกแล้ว ปิดหน้าต่างสีดำนั้น ระบบจะหยุด

- ถ้า Windows ถามว่าจะให้เปิดไฟล์นี้ไหม ให้กด More info แล้ว Run anyway
- ข้อมูลไม่ได้บันทึกลงไฟล์ ปิดแล้วเปิดใหม่จะกลับเป็นชุดตั้งต้น 8 รายการ (MR-0001 ถึง MR-0008) และต้องเข้าสู่ระบบใหม่
- กลับเป็นชุดตั้งต้นโดยไม่ต้องปิดระบบ: เรียก `POST /api/reset` (ต้องเข้าสู่ระบบ)
- ถ้าหน้าต่างสีดำขึ้นว่า Port 3100 is already in use แปลว่าเปิดระบบซ้อนอยู่แล้ว ให้ปิดหน้าต่างเก่าก่อน

ข้อ 3 ทำโปรแกรมรวมไฟล์

เขียน merge_reports.py ที่: - อ่านทุกไฟล์ใน reports/ (CSV และ xlsx) ห้ามแก้หรือเขียนทับไฟล์ใน reports/ - ทำความสะอาด: วันที่ทุกแบบเป็น YYYY-MM-DD (พ.ศ. ลบ 543), ชื่อไซต์ให้เป็นชื่อเดียวกัน, ตัดแถวว่าง, ตัดแถวซ้ำตามเลขที่ใบส่งของ, ตัวเลขที่มีคอมมา, หน่วยไม่ตรง price-list.csv ให้แปลงตามหมายเหตุใน price-list.csv - ออก output/summary.xlsx 2 ชีต: "รายการ" (ข้อมูลสะอาดแล้ว) และ "สรุป" (ไซต์ × วัสดุ: จำนวน, มูลค่า) - ออก output/rejected.csv (utf-8-sig) แถวที่ใช้ไม่ได้พร้อมเหตุผล - ท้ายการรันพิมพ์: อ่านกี่แถว ใช้กี่แถว ซ้ำกี่แถว ทิ้งกี่แถว มูลค่ารวม ใช้ Python มาตรฐาน + openpyxl (ติดตั้งด้วย python -m pip install openpyxl) อ่าน CSV ด้วย encoding utf-8-sig รันจริงแล้วแสดงผลที่พิมพ์ออกมา

อยากได้อะไร: หน้าเว็บไฟล์เดียว estimate.html สำหรับประเมินราคาวัสดุก่อนขอซื้อ ใช้ในเครื่องตัวเอง ใช้ข้อมูลจาก: ราคาจาก price-list.csv ฝังลงในไฟล์ อยากได้ผลแบบไหน: เลือกวัสดุ ใส่จำนวน เพิ่ม/ลบแถว, แสดง มูลค่าสินค้า / VAT 7% / รวมทั้งสิ้น ทศนิยม 2 ตำแหน่ง ปัดตามปกติ (ตำแหน่งที่ 3 ตั้งแต่ 5 ปัดขึ้น) คำนวณเป็นสตางค์เพื่อกันทศนิยมเพี้ยน ปุ่ม "ดาวน์โหลด CSV" (UTF-8 BOM ให้ Excel เปิดภาษาไทยได้), จำรายการล่าสุดไว้ในเบราว์เซอร์ หน้าตา: ภาษาไทย ตัวอักษรอย่างน้อย 16px ใช้บนมือถือได้ ห้ามทำอะไร: ห้ามโหลดไลบรารีหรือฟอนต์จากอินเทอร์เน็ต ห้ามส่งข้อมูลออกจากเครื่อง ดูยังไงว่าถูก: รัน server ในเครื่องที่ http://127.0.0.1:8000 แล้วใช้ @Browser เปิด http://127.0.0.1:8000/estimate.html ใส่ MAT-001 10 ถุง + MAT-003 2 ลบ.ม. แล้วบอกตัวเลขที่หน้าจอแสดง

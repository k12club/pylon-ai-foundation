ไฟล์ฝึกที่ใช้ตั้งแต่ลองทำ 0 จนจบคอร์ส โหลดครั้งเดียว แตกไว้ในโฟลเดอร์ codex-practice แล้วใช้ได้ทุกครั้งที่เรียน

practice-kit.zip

ชุดเดียวใช้ได้ทั้งสาย QA และสายหน่วยงาน ข้อมูลข้างในเป็นข้อมูลสมมติทั้งหมด

ดาวน์โหลด practice-kit.zip

แตกไฟล์ (ไม่ต้องพิมพ์คำสั่ง)

  1. เปิด File Explorer พิมพ์ %USERPROFILE% ในช่องที่อยู่ด้านบน กด Enter แล้วสร้างโฟลเดอร์ใหม่ชื่อ codex-practice ถ้ายังไม่มี
  2. เปิดโฟลเดอร์ Downloads คลิกขวาที่ practice-kit.zip เลือก Extract All
  3. กด Browse เลือกโฟลเดอร์ codex-practice แล้วกด Extract จะได้โฟลเดอร์ codex-practice\practice-kit

ข้างในมีอะไร

  • prompts.htmlข้อความลองทำทุกข้อ ดับเบิลคลิกเปิด แล้วกดคัดลอกไปวางใน Codex
  • commonพื้นฐานที่ทุกคนเรียน: สรุปประชุม รวมไฟล์ยอดขาย และ skill ของทีม
  • qaข้อกำหนดและระบบเบิกวัสดุตัวอย่าง สำหรับ QA-1 ถึง QA-5
  • bizรายงานรับวัสดุ 3 ไซต์ ราคาวัสดุ และแบบหนังสือ สำหรับ BIZ-2 ถึง BIZ-4
  • README.mdวิธีแตกไฟล์ และแต่ละโฟลเดอร์ใช้ฝึกเรื่องไหน

โหลดใหม่ได้ทุกเมื่อ ถ้าไฟล์ฝึกหายหรือพัง ให้โหลดแล้วแตกใหม่ ถ้าแตกทับโฟลเดอร์เดิม Windows จะถามก่อนแทนที่ไฟล์ และที่แก้ไว้ในไฟล์เดิมจะหายไป

ชื่อบริษัท โครงการ และผู้ขายในชุดฝึกไม่มีอยู่จริง บัญชีในระบบตัวอย่างใช้ได้กับระบบฝึกในเครื่องเท่านั้น ถ้าโหลดไม่ได้ ให้ถามผู้สอน
